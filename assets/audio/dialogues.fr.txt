DIALOGUES AUDIO DE NOLICE — VALIDÉS

Voix retenue : Jeanne — Narrator (txtf1EDouKke753vN8SL)
Modèle retenu : eleven_v4
Format : nom du fichier.mp3 | texte prononcé
Les titres et commentaires ne sont pas à prononcer.
Ce fichier est la source des textes pour le script de génération.

RÈGLES DE GÉNÉRATION
Voix naturelle de Jeanne : stabilité 0,5 ; similarité 0,75 ; français ; MP3 44,1 kHz / 128 kb/s.
Transmettre uniquement la phrase validée, sans balise de douceur, de chuchotement ou SSML.
Conserver une phrase continue : ne pas ajouter de pause ou de ponctuation après « Voici ».
Une génération peut varier en intonation malgré des réglages identiques : écouter avant intégration.
Si une prise ne convient pas, régénérer uniquement ce fichier et comparer avec la version précédente.
Le script conserve les nouvelles prises et leurs réglages dans output/audio, sans remplacer les assets.
Aperçu sans génération : npm run audio:samples -- --file response-losange.mp3
Nouvelle prise : npm run audio:samples -- --file response-losange.mp3 --generate
Les 28 réponses animaux, formes et couleurs : npm run audio:samples -- --responses --generate
Les 11 phrases des récompenses à débloquer : npm run audio:samples -- --unlocks --generate
Les 3 phrases du parcours de bienvenue : npm run audio:samples -- --welcome --generate
Les 3 phrases des récompenses gagnées : npm run audio:samples -- --rewards --generate
Les 52 phrases des lettres : npm run audio:samples -- --letters --generate

AFFICHAGE ET AUDIO
Les consignes restent courtes à l’écran, plus complètes à l’oral.
Couleurs : « Trouve le noir » affiché / « Trouve la couleur noire. » prononcé.
Comptage : « Combien de lapins ? » affiché / « Combien comptes-tu de lapins ? » prononcé.
Lettres : « Trouve la bonne lettre » affiché, sans la lettre, qui serait la réponse / « Trouve la lettre N. » prononcé.
Les résultats affichent « La réponse : … », même si la voix dit « Voici… ».
« Dommage ! » est affiché et prononcé après une mauvaise réponse.
Récompense verrouillée : la fenêtre affiche la règle exacte (« au moins 9 bonnes réponses sur 10 ») / « Pour avoir cette mascotte, gagne le jeu… » prononcé.

ENCHAÎNEMENTS
Après chaque réponse : bravo.mp3 ou dommage.mp3, puis le fichier response-*.mp3.
Exemple : « Dommage ! Voici la couleur noire. »
Comptage : « Bravo ! La réponse est huit. »
Score 0 à 4 : retry.mp3 ; titre « Bien essayé ! ».
Score 5 à 8 : congratulation.mp3 ; titre « Bien joué ! ».
Score 9 : score-almost.mp3 ; titre « Bravo ! ».
Score 10 : score-perfect.mp3 ; titre « Bravo ! ».
Récompense gagnée (score 9 ou 10) : après la phrase de score, le fichier reward-*.mp3 de sa sorte ; la carte affiche « Nouvelle mascotte ! ».
Fenêtre d’une récompense verrouillée (Réglages) : le fichier unlock-*.mp3 de sa règle, à l’ouverture.
Parcours de bienvenue : le fichier welcome-*.mp3 de l’étape, à l’arrivée sur l’étape (retour en arrière compris).
Chaque phrase unlock-* nomme la sorte de récompense que sa règle débloque : la régénérer si le plan des récompenses change.
